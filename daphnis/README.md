# Daphnis

Deployment and infrastructure-as-code for Daphnis.

```
# TODO Change this to DATABASE_DDC_URL for proper namespacing

DATABASE_ADMIN_PASSWORD

DATABASE_DDC_NAME
DATABASE_DIRECTORY_POSTGRES
FONTAWESOME_NPM_AUTH_TOKEN
PROTOCOL_AND_HOST
RANDOMLY_GENERATED_SECRET
```
